Translator Translator Translator

A translator that translates using only translations.

Your word becomes 128 numbers, gets multiplied by a matrix or two, and comes out the other side as a different word. Often even a related one.

      How it works

      Short version: we used translations to build a translator, which we then use to make translations. Long version:

      1. Every word is a point

        Each language gets its own word embedding: a cloud of points in a high-dimensional space, learned from mountains of text, where words that show up in similar places land near each other. katt sits near hund, gato near perro. We squash each cloud down to 128 dimensions so it fits through your internet connection.

        Crucially, each cloud was learned separately. Dimension 37 of Norwegian space has nothing to do with dimension 37 of English space. They have never met.

      2. The clouds have the same shape

        Here's the trick (Mikolov et al., 2013): since every language needs to talk about cats, dogs, beer and taxes, the clouds end up with roughly the same shape. One is approximately a rotated version of the other. So if we can find the rotation, we can translate.

      3. Find the rotation… using translations

        Take a few thousand known translation pairs, stack the Norwegian vectors in X and the matching English ones in Y, and find the rotation that lines them up best:

        W = arg minW⊤W = I ‖XW − Y‖ = UV⊤,  where  UΣV⊤ = svd(X⊤Y)

        That's the orthogonal Procrustes problem, solved in one line. Then we polish it with a few rounds of self-learning (Artetxe et al., 2017). Yes: to build the translator we first needed a pile of translations. We are aware. Please do not tell the philosophers.

      4. Everything goes through English

        Our dictionaries all go to and from English, so English is the hub. Norwegian → Japanese is really Norwegian → English → Japanese:

        vja = Wja⊤ Wno vno

        Rotations are their own undo button (W⊤ = W−1), so one matrix per language is enough. A side effect: in Express mode, detours cancel out exactly. You can route through Greek and Polish and the vector won't notice a thing.

      5. Pick the nearest word

        The rotated vector almost never lands exactly on a word, so we take the closest one by cosine similarity. In Telephone mode we do that at every stop, which is where things start to drift. Sometimes hilariously.

        That's it. That's the whole translator. No grammar, no context, no idea what any of it means.
